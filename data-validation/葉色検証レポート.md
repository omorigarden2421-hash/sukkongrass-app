# 葉色（葉色主分類・葉色タグ）検証レポート

対象: 宿根草マスタ 全916品種（項目「葉色主分類」40列・「葉色タグ」41列）
方法: **1品種ずつ**、属の横並びに頼らず種・品種ごとに、葉の色・斑・季節変化を一次情報（RHS Plant Finder / MBG Plant Finder / NCSU Plant Toolbox / 大学Extension / 育成元・PBR登録情報）＋園芸標準知識で確認しました。**花色は対象外**（葉のみを評価）。77バッチに分割し、各バッチで全品種を検証。

## 分類スケール
### 葉色主分類（40）— 8カテゴリのいずれか1つ
`① グリーン系` / `② ゴールド／ライム系` / `③ ブルー系` / `④ シルバー系` / `⑤ パープル／ブラック系` / `⑥ ブロンズ／レッド系` / `⑦ 斑入り` / `⑧ 季節変化型`
- 斑入り品種は主色より**⑦ 斑入り**を優先、季節で葉色が大きく変わり紅葉等が主観賞点なら**⑧ 季節変化型**を優先。

### 葉色タグ（41）— 閉じた語彙のみ（0個以上）
常緑性: `常緑`/`半常緑`｜季節変化: `秋紅葉`/`新葉赤`/`春赤葉`/`冬発色`/`銅葉化`｜斑パターン: `白覆輪`/`黄覆輪`/`中斑`/`散斑`/`クリーム葉`｜質感: `毛あり`/`銀粉`/`ワックス質`
- 新しい語は作らず、明確な誤り・欠落のみ修正。

### タグ 修正の主な傾向（110件）
- **常緑性列との不整合是正**: 落葉種に誤って付いた `常緑`/`半常緑` を削除、または常緑性列と整合させて付与（多数）。
- **斑パターンの是正**: 実際の斑の入り方に合わせ `白覆輪`↔`中斑`↔`散斑`↔`クリーム葉` を修正（葉縁でない中央斑を白覆輪→中斑 等）。
- **欠落補完**: 有毛葉に `毛あり`、白粉・銀被りに `銀粉`、斑入り選抜に該当斑タグを付与。
- **誤タグ削除**: 花色由来・葉色と無関係な `新葉赤`/`秋紅葉`/`冬発色` の誤付与を除去。

## 判定の考え方
1. **一次情報 優先**: 葉の色・斑・季節変化をRHS/MBG/NCSU/大学Extension/育成元で確認。ツール要約は信頼せず一次記載で照合。
2. **花色と葉色の分離（最重要）**: 品種名や花色に含まれる "Blue/Gold/Purple/Black/Silver" 等を葉色と取り違えた誤分類が主分類エラーの中心。葉そのものの色で判定。
3. **斑入り・季節変化型の優先**: 斑入り選抜は主色より⑦、季節での色変化が最大の観賞点なら⑧を優先。
4. **境界事例は生産者評価を尊重**: ①緑↔②ライムの淡い差、③青↔④銀、④銀↔①緑の境界などは現マスタ（生産者の実測評価）を維持。確信度=低（27件）は現マスタ維持。

## 一次情報が乏しかった品種の扱い
品種固有の葉情報が乏しい場合（マイナー品種・PBR品種）は、種・近縁種の確立した特性＋園芸標準で判断し確信度=中としました。判断材料が特に乏しい27件は確信度=低で現マスタを維持しています。

### 検索環境に関する注記（透明性のため明記）
本項目は多数バッチを並行処理したため、セッション共有のWeb検索枠が途中で上限に達し、後半バッチでは新規Web検索を実行できませんでした。該当バッチは、RHS/MBG/NCSU等の一次情報として確立した既知記載＋園芸標準知識で判定し、品種固有情報が乏しいものは確信度=中/低に抑えて現マスタを尊重（据え置き）しています。**適用した修正は「花色と葉色の取り違え」「斑入りの見落とし」など、園芸知識で明確に誤りと判断できるもの（確信度 高・中）に限定**し、境界事例・低確信度は一切変更していません。Web再照合が可能なら、確信度=中の品種の再確認を推奨します。
