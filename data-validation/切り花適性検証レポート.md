# 切り花適性 検証レポート

対象: 宿根草マスタ 全916品種（項目「切り花適性」37列）
方法: **1品種ずつ**、既に検証済みの特性（草丈・広がり・成長習性・常緑性）を手がかりに、切り花・花き専門の一次情報（RHS の "good for cutting" / cut flower 記述、MBG Plant Finder の "good fresh cut flower"、切り花生産者・フローリスト情報＝ASCFG / Floret / Farmer Bailey / 大学Extension の cut flower guide、花保ち（vase life）データ）で確認。属の横並びに頼らず、種・品種ごとに評価しました。

## 評価スケール（現マスタ準拠の3段階）
- **◎**: 優れた切り花・切り葉素材。長くしっかりした花茎＋良好な花保ちで花き市場・フローリストの定番（エキナセア、アスチルベ、アキレジア、シャクヤク、リアトリス、スカビオサ、ジプソフィラ、ベロニカストラム、エキノプス、切り葉になるグラス類 等）
- **○**: 中程度に使える。花茎がやや短い／花保ちが中程度／混合花束の脇役・小花素材・切り葉
- **△**: 切り花に不向き。花茎が極端に短い・無い、切るとすぐ萎れる、地を這うマット／ロゼット／観葉グラウンドカバーで「切って使う」概念が当てはまらない

## 判定の考え方
1. **一次情報 優先**: RHS の cut flower 用途タグ、MBG の "good fresh cut flower / useful in arrangements"、切り花生産者・フローリストの実利用（ASCFG / Floret / Farmer Bailey / 大学Extension の cut flower factsheet）、花保ち（vase life）を確認。ツール結果の要約は信頼せず一次情報で照合。
2. **検証済み特性との整合**（重要）:
   - 草丈が高め（40cm〜）で直立の花茎を持ち、花・穂が観賞価値高い → ◎〜○。
   - 成長習性=マット型／ロゼット型／匍匐や草丈が極端に低い（〜15cm程度）で切る花茎がない → △。
3. **切り葉（cut foliage）も評価対象**: ホスタ・ヒューケラ・ベルゲニア・斑入りグラス等、花より葉が花き市場で流通する素材は、地被扱いの△から○へ是正（多くはフローリスト定番だが花より脇役のため◎ではなく○止まり）。
4. **生産者評価の尊重**: 1段階差で情報が曖昧なら現マスタ維持。**2段階以上のズレ・方向逆転**（定番切り花を△、マット地被を◎等）を優先修正。確信度=低（12件）は現マスタ維持。

## 代表的な修正例
- **ジプソフィラ各種（○→◎）**: カスミソウはフローリスト定番のフィラー切り花、しっかりした花茎＋花保ち7〜14日。
- **エリンジウム プラナム（○→◎）**: MBG が「excellent for cut or dried flower arrangements」、切り花市場向け育成。
- **ベロニカストラム／エキノプス／サンギソルバ（○→◎）**: 高性・直立の穂物で近年フローリスト定番。
- **ホスタ／ヒューケラ 多数（△→○）**: 切り葉として花き市場で流通・花保ち良好。地被扱いの△は方向誤り。
- **フッキソウ・匍匐タイム・匍匐ベロニカ・セラトスティグマ（○→△）**: マット状地被で切る花茎がなく切り花不向き。
- **矮性クッションアスター、低草丈カレックス（◎→○／△）**: 花茎が短く「◎定番」の要件（長くしっかりした花茎）を満たさない過大評価を是正。

## 一次情報が乏しかった品種の扱い
品種固有の切り花・花保ちデータが乏しい場合（園芸品種・PBR品種・マイナー種）は、種・近縁種の切り花評価＋検証済みの草丈・成長習性＋花き標準で判断し、確信度=中としました（119件）。判断材料が特に乏しい12件は確信度=低で現マスタを維持しています。
