# 自走（オートパイロット）計画・再開手順

大森ガーデンの宿根草マスタ（全916品種）の残り検証項目を、指示なしで1品種ずつ検証していく作業の計画書。
クレジット上限で中断しても、1時間ごとの定期トリガーで自動再開する。コンテナが破棄されても本ファイルと
リポジトリの成果物・作業用マスタから状態を復元して継続する。

## 除外（調査しない）
- 特徴 / 花時期 / 花色 / 日照条件

## 作業ルール（既存の全項目と統一）
- 1品種ずつ、一次情報（MBG Plant Finder / RHS / NCSU / 大学Extension / 育成元）でWeb照合。属の横並び推論に頼らない。
- 変更は「明確な誤り・方針レベルのズレ」のみ。境界的な差は生産者の実測を尊重（現マスタ維持）。確信度=低は現マスタ維持。
- 出力: 項目ごとに `data-validation/<項目>検証レポート.md` ＋ 修正ログCSV ＋ 全916監査CSV。
- 反映: `data-validation/_autopilot/master_working_latest.xlsx` を基点に該当列のみ更新して上書き保存。
  赤塗り版 `..._赤塗り_latest.xlsx` の対象列も更新。整合性チェック（対象列以外不変・917×70・コメント2件維持）。
- 各項目の完了ごとに commit ＆ push（ブランチ `claude/perennial-master-data-validation-aqs8jv`）。
- 完了項目はユーザーに納品（修正版マスタ＋赤塗り版）。

## 再開時の手順（フレッシュなコンテナでも）
1. `data-validation/_autopilot/master_working_latest.xlsx` を作業基点として読む。
2. 本PLANの作業キューで未チェックの最上位項目を選ぶ。
3. その項目を1品種ずつ検証 → 該当列のみ反映 → レポート/CSV作成 → commit&push → 納品。
4. PLANのチェックを更新してcommit。全キュー完了ならトリガーを削除して終了報告。
