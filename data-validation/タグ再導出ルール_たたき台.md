# タグ列 再導出ルール（たたき台 v0.1）

対象4列を、検証済み事実列から**決定ルールで機械再導出**する。事実から一意に決めにくいトークンは**現状維持**（事実だけの更新はしない＝そのまま残す）。

- 対象タグ列: **38 用途区分 / 61 景観構成用途タグ / 62 機能用途タグ / 63 デザイン系タグ**
- 参照する事実列: 12高さ / 14日照 / 24乾燥耐性 / 23土壌水分 / 35成長習性 / 37切り花適性 / 40葉色主分類 / 55蜜源価値 / 57成株シルエット
- 高さの解釈: セルは範囲表記が多い（例「80～120」「40(60)」）。**記載中の最大値**を採用（景観上の最大到達高で配置）。

---

## A. 景観構成用途タグ（61） ← 高さ(最大) の3区分 【確定】

| 最大高 H (cm) | タグ |
|---|---|
| H ≤ 30 | 前景 |
| 31 ≤ H ≤ 80 | 中景 |
| H ≥ 81 | 後景 |

- 3区分（前景／中景／後景）。中間表記（前景〜中景・中景〜後景）は廃止。
- 想定件数：前景225 / 中景406 / 後景281。
- 高さ欠測（4件）は現状維持。

## B. 用途区分（38） ← 61の3区分 ＋ グラウンドカバー付与 【確定：3区分】

| 61の帯 | 用途区分の基本形 |
|---|---|
| 前景 | 前景・縁取り |
| 中景 | 中景構成 |
| 後景 | 後景・背景 |

- **グラウンドカバー付与【確定】**：成長習性(35) ∈ {マット型, ランナー型} の場合、基本形の末尾に「、グラウンドカバー」を追加。該当104件。
  - 根拠: 現行GC付与95件のうち91件がこの条件を満たす。外れる4件（叢生・つる型）は誤付与とみなし除外。高さは非関与（GC有無とも10–60cmに分布）のため高さ条件は付けない。

## 全体の進め方

1. このルールで **A/B/C/D を再導出 → 現行との差分（追加/削除/変更）を列ごとに件数＋サンプルで提示**（プレビュー、まだ書き換えない）。
2. ⚠印の判断ポイントを確定。
3. 承認後、マスタ（宿根草マスタ_検証済み_最終版.xlsx）へ一括適用し、変更ログCSVを残してコミット・プッシュ。

## 要確認（⚠）まとめ 【全6点 確定済み】
1. ✅ 景観は3区分。境界 **≤30 / 31–80 / ≥81**（前景225 / 中景406 / 後景281）。用途区分38も同3系統＋GC。

4. ✅ カラーリーフは**⑧季節変化型を除外**（②③④⑤⑥⑦のみ）。
