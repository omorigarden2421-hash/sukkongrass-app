# 宿根草マスタデータ 検証

ColorMe Shop からエクスポートした商品マスタ（`product_20.csv`、CP932）に含まれる
宿根草 **1,148 品種** を1品種ずつ検証し、商品説明内の学名・原産地などの誤りを洗い出した結果です。

## 修正済みCSV（`product_20_corrected.csv`）について

- **214件**を自動適用しました（学名 177件／原産地 37件）。変更したのは各商品の「商品説明」欄の学名・原産地のみで、他の列・行は元のままです（1,172行×60列を保持）。
- 文字コードは元と同じ **CP932（Shift-JIS）**、改行 CRLF、全項目ダブルクォートで、ColorMe Shop の商品CSVインポートにそのまま使えます。
- **方針**: 分類変更（Aster→Symphyotrichum 等の学術的再分類）は園芸流通で通用する**旧属名を維持**し、書式（全角・スペース）のみ整えました。学名の綴り・全角混入・原産地の誤り・別植物からの転記（クローン誤り）などの実質的な誤りを修正しています。
- **未適用（6件・要人手確認）**: 商品説明が空（190727481）、レコードがセル内改行で分断（190882681）、品種名の一次情報が未確認（184389144 'Happy Snow'）、および学名自体は妥当で商品名側の判断になるもの（132137289 / 141375223 / 172613372）。詳細は `changelog.csv` に含まれない分としてレポート側を参照。

## 検証の観点

- 学名（属名・種小名・品種名）の綴り・妥当性
- 商品名（カタカナ）と学名の整合（別植物の説明を流用した「クローン誤り」の検出）
- 原産地の妥当性
- 全角英字・全角スペースの混入（文字化け由来）
- 属名と品種名の癒着・書式の乱れ
- 現代分類での属変更（参考情報）

## 検出サマリー（236件）

- 確信度: 高 132 / 中 78 / 低 26
- 最優先: 商品名と学名の不一致（クローン誤り）
- 最多・系統的: 原産地の誤り、ラテン語綴り誤り、全角文字混入

詳細は `宿根草マスタ検証レポート.md` を参照してください。
確信度「低」の項目は人手での最終確認を推奨します。
