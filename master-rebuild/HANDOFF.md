# 引き継ぎ（クラウドのセッション → パソコン上のセッション）

## 目的
宿根草の生産者（北海道広尾町）の通販・卸用マスターデータを、文献だけを根拠に作り直している。
28品種で試作済み。パソコン上のセッションでは、クラウドから読めなかった文献を読み、試作に反映してから全件（約1,000品種）に進む。

## まず読むもの（このフォルダ内）
- DECISIONS.md … これまでの決定事項（最優先）
- trial/SPEC.md … 文献調査の仕様（集める項目・出力形式）
- trial/RULES.md … 文献の記述をマスターの区分に当てはめるルール（DECISIONS.md の変更が優先）
- trial/evidence/ … 試作28品種で集めた文献の記述（原文・URL付き）
- trial/rows/ … 当てはめた値
- scripts/assemble.py … 試作マスター（Excel）を組み立てる。元のマスター（価格・在庫を含む Excel）はユーザーの手元にあり、リポジトリには入れていない（公開リポジトリのため）

## パソコン上でやること
1. クラウドでは読めなかった文献を、試作28品種について読み、trial/evidence/ に追記する（SPEC.md の形式。source に文献IDを付ける）
   - s02 MBG（missouribotanicalgarden.org）… 乾燥・暑さ・病害虫・増え方
   - s04 YList（ylist.info、http のみ）… 和名
   - s11 Jelitto（jelitto.com）… こぼれ種・耐塩性
   - s17 Gaißmayer（gaissmayer.de、ナーサリーだが使用可）… 草丈・株張り・花期・日照・土壌
   - s18 stauden.de の無料データベース（staudendatenbank.html）… まず中身を見て、有料版（Rita Bosse の Profi-Stauden-Datenbank、見積もり制）を契約するかユーザーが判断する
   - Cloudflare などで止められるサイトは、Claude in Chrome（ブラウザ拡張）で読む
2. DECISIONS.md の決定（耐暑性は記述がなければ空欄、植え付け適期は削除、常緑性は1列、切り戻し時期は「花後」だけ、など）を RULES.md と assemble.py に反映し、試作表を作り直す
3. 未決事項をユーザーに確認する（DECISIONS.md の「未決」）。ユーザーは確認事項をチェックリスト形式で答えるのを好む
4. 試作が固まったら、全件へ進む手順をユーザーと決める

## 注意
- 文献にない値は推測で埋めない（空欄）。値ごとに文献ID・原文・URL・確認日を残す
- 文献値・自社の実測値・設計上の推奨値は分けて管理する
- 価格・在庫を含むデータは公開リポジトリにコミットしない
