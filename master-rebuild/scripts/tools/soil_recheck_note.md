# 土壌水分の再検証（決め方）

2026-11-26 の読み直し（soil_reread.json）で、土壌水分が今のマスターと違う値になった品種を、別の係がもう一度、文献から決め直す（ユーザー「再検証」2026-11-27）。

- 値の決め方は `scripts/tools/soil_reread_note.md` と同じ（まずそれを読む）。値の読み方・文献の順・段階の使い方はそのとおりにする
- 入力には、前の読み直しの値は入れていない。文献だけを見て、自分で決める
- 入力の「今のマスター」は、今の表に入っている値。これを支える文献の値や文が入力にあるかも確かめる。支えるものがあれば、その原語を短く引用する。なければ null
- 今のマスターの値は日本の育て方や生産者の経験から来ていることがある。入力にない文献を想像で補わない。推測で値を作らない
