# 品種なのに種のページの値を使った項目の確かめ（決め方）

宿根草916品種のマスター（北海道広尾町の生産者）。切り花適性と蜜源価値は、品種名のある商品でも、品種のページに記述がないとき種のページの値を使った（切り花は ○ まで・確かさ 低。DECISIONS.md 2026-11-26）。ユーザーは「これは心配だね」（2026-11-27）。品種の性質が種と違えば、種の値は当てはまらない。1品種ずつ確かめる。

## 見ること（入力にあることだけで決める）
- **八重咲き・不稔**：品種名（Plena・Flore Pleno・Double・Pompon など）や、品種のページ・花色の詳細の記述に、八重咲き・花粉や蜜がない・種ができない、とあれば、蜜源の種の値は当てはまらない → 外す
- **背の低い品種（切り花）**：品種のページに dwarf・compact・low・groundcover とある、または草丈の最大が 30cm 以下なら、種のページの「切り花によい」は当てはまらないことが多い → 迷う（草丈と一緒に出す）
- **品種のページがはっきり逆を言う**：品種のページに「切り花に向かない」「花が目立たない」「ハチが来ない」などとあれば → 外す
- **葉を見る品種**：品種のページが葉の観賞だけを言い、花を「目立たない・切り取る」とするなら → 迷う
- 何もなければ → 残す（種の値のまま）

## 守ること
- 入力にない知識で決めない（「この品種は八重のはず」と思っても、入力の名前や記述にそう書いていなければ 残す か 迷う にし、メモに書く）
- 値を上げない（○ を ◎ にしない）。外すか、残すか、迷うか、だけ
