# 耐暑性・蒸れ耐性の読み直し（決め方）

宿根草916品種のマスター（北海道広尾町の生産者。お客様は本州にもいる）。文献の文から、耐暑性と蒸れ耐性を決め直す。
**文献の文は意味で読む（キーワードの一致だけで決めない）。推測で値を作らない。当てはまる記述がなければ null。**

## 入力（1行1品種の JSON）
- 文: 暑さ・蒸れ・湿り・日差しに関わりそうな文を、文献ごとに全部。頭の [文献・段階]（段階: 品種／種／属）
  - 文献: MBG（ミズーリ植物園、セントルイス＝夏が高温多湿）、NC State（ノースカロライナ州立大、米国南東部＝高温多湿）、RHS（英国王立園芸協会）、Walters（米国の生産者）
- おぎはら図鑑: おぎはら植物園（長野県のナーサリー）の図鑑の耐暑性（強／中）と段階
- おぎはら同じ種の別品種: [値, [品種名…]]（このページがない品種で、同じ種の別品種がどれも同じ値のとき）
- おぎはら楽天: おぎはらの楽天の商品ページの欄（heat＝耐暑性、humid＝耐湿性、sun_cool／sun_warm＝寒冷地／暖地の日照、dry＝耐乾性 など。欄名は入力のまま）
- 今の値: 今のマスターの値（比べるため）

## 定義
- 耐暑性＝気温（暑さ）への強さ。基準は「暖地での夏越し」：強＝暑さに強い、中＝暖地では涼しいところで夏越しするなど工夫が要る、弱＝暖地では夏越しが難しい（寒冷地向き）
- 蒸れ耐性＝夏の高温多湿・空気の湿気・株の蒸れへの強さ。**土の湿りすぎ（排水の悪い土・湿った土・粘土で腐る・冬の湿り）は蒸れではない**（使わない）。「湿った土を好む」も蒸れに強い根拠にしない

## 手順1：欧米の文献だけでの判定（「欧米耐暑」「欧米蒸れ」）
- 耐暑性
  - 弱：暑さを嫌う・冷涼な気候が必要・冷涼な夏を好む（performs best in cool summer climates など）・暑い夏に弱る／枯れる、の明記
  - 中：条件つきで育つ記述だけ（暑い地域では午後の日陰を好む、暑い所で日なただと葉が焼ける、穏やかな夏を好むが枯れる記述はない、南部では夏に傷む・見苦しくなる）
  - 強：heat tolerant・tolerates heat・南部の暑さでもよく育つ、などの明記
  - 文献が割れたら控えめな側（強と条件つきが両方あれば 中）。属の記述（段階＝属）は種・品種の記述があればそちらを使う
  - USDA ゾーンの上限・原産地からは決めない
- 蒸れ耐性
  - 弱：高温多湿で溶ける（melt out）・多湿で株腐れ・高温多湿の地域に向かない／耐えない、の明記
  - 中：多湿で姿が乱れる・病気（うどんこ病など）が出やすいが維持できる、風通しが必要、乾いた空気を好む
  - 強：humidity に耐える・高温多湿の南部でよく育つ、の明記
  - 割れたら控えめな側。記述がなければ null
- 文献の順位（暑さ・蒸れ）：NC State > MBG > RHS > Walters。順位が上の文献の明記を優先するが、控えめな側の明記がほかにあれば控えめな側

## 手順2：おぎはら（最終の値）
- 耐暑性
  1. おぎはら図鑑に品種か種のページがあれば、その値（強／中）。楽天の heat がそれより控えめなら控えめな側
  2. なければ、おぎはら同じ種の別品種の値（信頼度 低）
  3. どちらもなければ、手順1の欧米耐暑
  4. おぎはらが 強 で 欧米耐暑 が 弱、かつ楽天のページに「高温多湿を嫌う」か暖地で日陰の注意（暖地の日照が半日陰・日陰、西日を避ける）があれば 中
- 蒸れ耐性：手順1の欧米蒸れと、楽天からの値の控えめな側
  - 楽天の耐湿性の説明に「高温多湿を嫌う」があれば、耐湿性が やや弱い・弱い なら 弱、普通以上なら 中
  - 耐暑性の補足が「暖地では夏に風とおし、水はけよく」だけなら 中
  - 楽天に書いていないことから 強 にはしない
  - 楽天の「耐湿性」の 強・中・弱 そのものは土の湿りなので使わない

## 出力
1品種1行の JSON（JSON Lines）。全品種を書く（今と同じでも書く）。
{"商品番号": …, "欧米耐暑": "強|中|弱|null", "欧米耐暑の決め手": "[文献・段階] 原文の短い引用", "欧米蒸れ": …, "欧米蒸れの決め手": …,
 "耐暑性": 最終, "蒸れ耐性": 最終, "今と違う": ["耐暑性", "蒸れ耐性", "欧米耐暑", "欧米蒸れ" のうち今の値と違うもの],
 "確かさ": "高|中|低", "メモ": "今と違う理由・迷った点（日本語、短く）"}
- 今の値の「耐暑性（欧米の文献だけなら）」「蒸れ耐性（欧米の文献だけなら）」が欧米耐暑・欧米蒸れの今の値
- 迷ったら null にせず、いちばんよい読みを書いて 確かさ を 低 にし、メモに理由
