# 冬の手入れの文の再検証（決め方）

2026-11-27 のそろえ直し（`scripts/tools/winter_unify_note.md`）は、機械で疑いを拾った276品種だけを見た。残りの品種を1つずつ読み、同じような食い違いや誤りが残っていないか確かめる（ユーザー「再検証」2026-11-27）。

まず `scripts/tools/winter_unify_note.md` を読み、そのそろえ方と守ることに従う。そのうえで、次も見る。

## 見ること
1. **文献どうしの食い違い**（unify_note の例と同じ）：残すと切るが並ぶ、常緑なのに地上部が枯れる、切る時期が2つ、など
2. **文と常緑性・植物の形が合わない**：低木・つる（木になるもの）に「冬は地上部が枯れます」「枯れた地上部を切ります」とある。常緑・半常緑なのに「枯れた地上部は冬のあいだ残します」とある。落葉なのに冬の葉の色だけを言う、など
3. **文と「事実」が合わない**：事実の値と逆のことが書いてある（事実は「春まで残す」なのに文は「晩秋に切る」など）。ただし、事実の値は係が上位の文献で選んだもの。文のほうが「決め手」の文献と合わないときだけ直す
4. **RHS の「No pruning required」（剪定不要）**：これは剪定（形を整える切り込み）がいらないという意味で、枯れた茎を冬の前後に片づける作業とは食い違わない。落葉の品種で、ほかの文献が「晩秋に枯れた茎を地際で切る」と言うなら、その文は残す。常緑・半常緑の品種で「晩秋に地上部が枯れたら地際で切る」は常緑性と食い違うので、上位の文献で決める
5. **北海道の文の最後の「雪が少ない年は、…」の一文は、この作業では変えない。**入力の文にはまだ入っていない（表を作るときに足す）

## 守ること
- unify_note の「守ること」のとおり。新しい事実を足さない。直すのは、食い違い・誤りのところだけ
- ただし 4 で、前のそろえ直しで外した「晩秋に地際で切る」を戻すのはよい（入力の「前のそろえ直し」に外した文がある）
- 問題がなければ、文はそのまま返す（「変えた」false）

## 入力（1行1品種）
植物名、学名、常緑性と根拠、事実（文献から抜き出した値・決め手・食い違い・メモ）、今の文・北海道、今の文・温暖地、前のそろえ直し（あれば：そろえる前の文と採った読み）

## 出力
1品種1行の JSON（JSON Lines）。全品種を書く。
{"商品番号": "…", "変えた": true|false, "北海道": "文"|null, "温暖地": "文"|null, "直した点": "何をどの文献でどう直したか（変えないときは null）", "メモ": "迷った点（なければ null）"}
