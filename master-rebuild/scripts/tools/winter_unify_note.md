# 冬の手入れの文で、食い違う事実を1つの読みにそろえる（決め方）

宿根草916品種のマスター（北海道広尾町の生産者）。「冬の手入れ（北海道）」「冬の手入れ（温暖地）」は、文献から抜き出した事実をつないで、読みやすく整えた文になっている（2026-11-26、winter_polish.json）。ところが、文献どうしが食い違う事実を両方そのまま並べた品種がある。ユーザーの指示「そろえる」（2026-11-27）にしたがい、1品種の中で同じ点について言うことが1つになるよう直す。

## 食い違いの例
- 「冬も株姿が残る／枯れた地上部は冬のあいだ残す」と「晩秋に枯れたら地際で切る」が並ぶ
- 「冬も葉が残る常緑性です」と「枯れた地上部は冬のあいだ残します」が並ぶ
- 「冬は地上部が枯れます」と「冬に葉が紫色を帯びる／温暖地では常緑」が並ぶ
- 切る時期が2つ（晩秋に切る、と、雪解け後に切る）並び、どちらで切ればよいかわからない

## そろえ方
1. **同じ点で文献が割れたら、上位の文献を採る。** 順番：RHS ＞ シカゴ植物園 ＞ NC State ＞ MBG ＞ Walters ＞ Gaißmayer ＞ stauden.de ＞ Jelitto ＞ おぎはら。ただし**耐寒性・越冬（冬の傷み・防寒・冬に枯れるか）だけはシカゴ植物園を最初に**する。どの文献が何を言ったかは「事実」の「決め手」「食い違い」「メモ」と「常緑性の根拠」で確かめる。「食い違い」欄にすでに「○○を採る」と書いてあれば、その選び方に従う
2. **品種のページは種のページより先。** 同じ順番の中でも、品種名のページの記述を種のページの記述より優先する
3. **地域で分かれるだけなら食い違いではない。** 「暖地では常緑、寒い地域では枯れる」のような書き方は：
   - 北海道の文には寒い地域の読みだけを書く（「暖地では常緑」は北海道の文から外す）
   - 温暖地の文には暖かい地域の読みを書く。ただし文献の言い方（「冬の穏やかな地域では」など）を強めない
4. **作業が違うだけなら食い違いではない。** 「晩秋に地際で切る」と「春に残った枯れ葉を取る」は両方残してよい（前後の順に並べる）。同じ作業の時期が2つ並ぶときだけ1つにする
5. **下書きで決まり文句として入った一文**（「枯れた地上部は冬のあいだ残します」など）が、常緑性や秋に切る事実と食い違うなら、その一文を消す
6. 常緑性が「常緑」「半常緑」なのに「冬は地上部が枯れます」とある、または「落葉」なのに冬の葉の色や常緑を言う、など常緑性の欄と文が割れたら、「常緑性の根拠」と「事実」の文献の順で決める。迷えば、品種ページの RHS と シカゴ を信じる

## 守ること
- **新しい事実を足さない。** 消すのは、負けた側の事実と、食い違いのもとになった決まり文句だけ。切る高さ・月・回数などを補わない
- 食い違っていない事実（防寒、冬の過湿・水はけ、寒冷地での記録、ほかの手入れ）は、意味を変えずに残す
- 「勧める文献があります」を「必ず」にしない。「不要」と書いていない品種に「不要」と書かない
- 北海道の文は「雪解け後」、温暖地の文は「早春（2〜3月）」の言い方を保つ
- です・ます調。文の中に文献名を書かない（「シカゴの試験では」は記録として残してよい）
- 食い違いがなければ、文はそのまま返す（「変えた」は false）
- 今の文が null なら null のまま

## 入力（1行1品種の JSON）
植物名、学名、常緑性（と根拠）、理由（機械で拾った疑い。外れのこともある）、事実（文献から抜き出した値と決め手・食い違い・メモ）、今の文・北海道、今の文・温暖地

## 出力
1品種1行の JSON（JSON Lines）。入力の全品種を書く。
{"商品番号": "…", "変えた": true|false, "北海道": "文"|null, "温暖地": "文"|null, "採った読み": "どの点でどちらの文献を採ったか（変えないときは null）", "メモ": "迷った点（なければ null）"}
