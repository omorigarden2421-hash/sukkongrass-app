# 冬の手入れの文を読みやすく整える（決め方）

宿根草916品種のマスター（北海道広尾町の生産者）。「冬の手入れ（北海道）」「冬の手入れ（温暖地）」は、文献から抜き出した事実を決まった言い回しでつないだ下書きになっている（2026-11-26）。これを、お客様が読む商品説明のように、自然で読みやすい日本語に整える（ユーザー「読みやすく整えて」）。

## いちばん大事な決まり
- **下書きと「事実」にない内容を足さない。** 切る高さ（地際5cm など）・月・回数・肥料・病気・株分け・花がらなど、入力にないことは書かない。一般的な園芸の知識で補わない
- **下書きにある内容を落とさない。** 常緑性、秋の地上部、春の手入れ、冬の姿、防寒、冬の過湿・水はけ、寒冷地での記録は、意味を変えずに全部残す
- 意味を強めたり弱めたりしない（「勧める文献があります」を「必ず」にしない。「防寒は不要」と書いていない品種に「不要」と書かない）
- 下書きが空（null）なら、整えた文も null

## 整え方
- 文はです・ます調。1品種あたり 2〜5文くらい。「春の手入れ：」「冬の姿：」「寒冷地での記録：」の見出しの形はやめ、ふつうの文にする
- 同じことの言い直しはまとめる（例：「冬のあいだ残し、雪解け後に切ります」と「春の手入れ：早春に強く切り戻す」→「冬のあいだは残し、雪解け後、新芽が出る前に短く切り戻します」）
- 季節の順に並べる：冬の姿（常緑か・地上部が枯れるか）→ 秋の手入れ → 冬の注意（防寒・過湿）→ 春の手入れ
- 北海道の文では「早春」を「雪解け後」と言い換えてよい。温暖地の文の「早春（2〜3月）」はそのまま使ってよい
- 「文献では…を勧めています」「…を勧める文献があります」は、意味を保てば「…すると安心です」「…がすすめられています」などに言い換えてよい。ただし「寒い地域では」の条件は落とさない
- 「寒冷地での記録」の中身（シカゴ植物園の冬の傷みなど）は、「寒さの厳しい冬に株元が傷んだという試験の記録があります」のように、記録であることがわかる書き方で残す
- 外国語の語・括弧の原語（Wintersteher など）は日本語にする。華氏などの換算は下書きにあるものだけ
- 北海道と温暖地の文で、同じ事実は同じ言い方にそろえる

## 入力（1行1品種の JSON）
- 植物名、常緑性、土壌水分、耐寒性（今のマスター）
- 事実：文献から抜き出した値（秋の地上部・春の手入れ・防寒・冬の過湿・冬の姿・雪・寒冷地）。下書きに使われなかった値もある（例：防寒「雪がない寒さで必要」は北海道の文に書かない決まり。「雪の少ない地域では」の記録も北海道に書かない）。**下書きにない事実を、この欄から足してはいけない**（確かめるためだけに使う）
- 下書き・北海道、下書き・温暖地

## 出力
1品種1行の JSON（JSON Lines）。全品種を書く。
{"商品番号": "…", "北海道": "整えた文"|null, "温暖地": "整えた文"|null, "メモ": "迷った点（なければ null）"}
