# 品種情報の出典ルール

版数: v1.2
最終更新: 2026-11-11
対象: 通販サイト・属ページ・カタログ・商品説明・記事など、お客様の目にふれる品種情報すべて

---

## 0. 要旨（3行）

1. **品種の事実は、一次情報（公的機関・植物園・大学・育成元）で確認できたことだけを書く。** 品種マスタは誤りが多いため、根拠にはしない（調べる手がかりとして使う）。
2. **生産者の経験にもとづく記述は、大森さんが確認したものだけを書く。** 設計の考え方は「大森ガーデン植栽設計教本」にもとづく。
3. **書く順序は教本の大原則「生きる > 見える > 売れる」に従う。** まず育つ条件、次に見せ方、最後に相談・購入の案内。

---

## 1. 情報源の区分

| 区分 | 情報源 | 何に使うか |
|---|---|---|
| **C** | 一次情報（下記） | **品種の事実の唯一の根拠**（原産地、草丈、咲く時期、花色、日当たり、土、耐寒性、病害虫など） |
| **B** | 大森さんが確認した生産者の経験・実測 | 北海道・十勝での育ち方、冬越しの実績、植え付け・切り戻しの実際など、一次情報にない生産者の知見 |
| **D** | 大森ガーデン植栽設計教本（第0〜8章） | 設計の考え方・用語・判断の順序（高さの層、組み合わせの考え方、用途の型） |
| 参考 | 品種マスタ | **根拠にはしない。** 調べる手がかりと、一次情報との食い違いを見つけるために使う |

**C（一次情報）として認めるもの**
- Missouri Botanical Garden（Plant Finder、園芸相談）
- 英国王立園芸協会（RHS）
- NC州立大学 Extension（Plant Toolbox）ほか、米国の州立大学 Extension
- Lady Bird Johnson Wildflower Center（テキサス大学）
- USDA PLANTS Database
- 植物和名の学術データベース（YList など）、国内の公的研究機関
- 品種の育成元（ブリーダー）の公式情報（その品種の特性に限る）

**B（生産者の経験）として認める条件**
- 品種マスタの「特徴」欄や商品ページに書いてある内容は、そのままではBにならない。**大森さんに確認して「正しい」と返事をもらったものだけ**をBとして記録し、使う。

---

## 2. 何をどこから書くか

| 書く内容 | 根拠 |
|---|---|
| 原産地・科名・通称 | C |
| 草丈・広がり・咲く時期・花色・葉色 | C（品種の数値は品種ごとの一次情報。属や種の値を品種に当てはめない） |
| 日当たり・土・乾燥・暑さ | C |
| 病害虫と対策 | C |
| 耐寒性 | **お客様向けの表示は、品種マスタとサイトの段階（強／中の強／中の中／中の弱／弱）を使う**（2026-11-11 大森さん決定）。段階の値が正しいかは、C（USDAゾーンなど）とB（十勝での冬越しの実績）で確認する |
| 北海道・十勝での育ち方、切り戻しの時期、冬越しの実績 | B（大森さんの確認） |
| 手前・中ほど・奥の高さの使い分け | **D：教本 第1章を基準にする**（2026-11-11 大森さん決定。前景20〜40cm／中景40〜90cm／背景90cm以上）。当てはめる草丈はCで確認した値 |
| 組み合わせ・用途の提案 | D（考え方）＋B（大森さんの確認）。それ以外は大森さんの承認後 |

**教本（D）の扱いの注意**
- 教本の「典型品種」の例は、設計の考え方を説明するための例であり、品種の性質の根拠にはしない。
- 教本の広尾町での草丈補正（本州の0.7〜0.9倍）を使った数値をお客様向けに書くときは、大森さんの承認を得る。

---

## 3. 使ってはいけない情報源

- 品種マスタ（誤りが多い。手がかりとしてだけ使う）
- 大森ガーデン自身の商品ページ（在庫・価格の確認にだけ使う）
- 通販サイト・園芸店・種苗店の商品説明（海外のナーセリーを含む）
- 個人のブログ、まとめサイト、SNS、Q&Aサイト
- Wikipedia（調べる入口にするのは可。根拠にはしない）
- AIが作った文章

---

## 4. 書く順序（教本 第8章「生きる > 見える > 売れる」）

1. **生きる**：育つ条件。耐寒性と冬越しの目安、日当たり、土、暑さ。北海道で冬を越せない種類があるときは、必ずはっきり書く。
2. **見える**：草丈と高さの使い分け、花色と咲く時期、組み合わせ。
3. **売れる**：取扱品種の一覧、相談への案内。

- 冬越しできない・育ちにくい条件を、見せ方や売りやすさのために弱めて書かない。

---

## 5. 書き方のルール

1. **1つの文に、必ず1つ以上の出典を対応させる。** 公開前に照合表（書いた内容／出典名とURL／結果）を作る。
2. **出典が見つからないことは書かない。** 推測で補わない。同じ属のほかの種や、種の値から品種を類推しない。
3. **数字・時期は、出典の値をそのまま使う。** 単位換算（フィート→cm など）をしたときは、換算前の値も照合表に残す。
4. **地域で違うこと（刈込時期など）は、北海道と本州を分けて書く。**
5. **お客様向けの文に内部の言葉を出さない。**（「成立条件」「第6章」「大原則」など）
6. **大森ガーデンの品ぞろえ・生産方法・実績についての主張**は、大森さんの確認なしに書かない。

---

## 6. 情報源が食い違うとき

| 食い違い | 扱い |
|---|---|
| C と 品種マスタ／商品ページ | Cを使う。品種マスタ・商品ページの誤りは一覧にして大森さんに報告（勝手に直さない） |
| C 同士 | 大森さんの実測（B）があればそれを使う。なければ書かない |
| C と B（大森さんの経験） | 両方を大森さんに見せて判断してもらう |
| C と D（教本の記述） | 品種の事実はCを使う。教本の見直しが必要なら、教本の課題として報告 |
| Cが見つからない | 書かない。必要なら大森さんにBとして確認する |

---

## 7. 大森さんの確認（オーナー監修）が必要なもの

- 生産者の経験にもとづく記述（B）すべて
- 組み合わせ・配置・用途の提案
- 耐寒性の段階の値が一次情報と合わないとき
- 大森ガーデンの品ぞろえ・生産方法・実績についての主張
- 教本の補正値を使ったお客様向けの数値

---

## 8. 公開までの手順

1. 品種マスタを手がかりに、品種ごとに一次情報（C）を調べる
2. 下書きを作り、照合表（出典名とURL）と「確認していただきたい点」（Bの確認、食い違い）を添えて大森さんに見せる
3. 大森さんの了承後に公開する
4. 公開後、公開ページの文章をもう一度照合表と突き合わせる
5. 照合表・Bとして確認した内容・食い違いの一覧をプロジェクトに記録する

---

## 9. 公開前の自己チェック

- [ ] 品種の事実の文すべてに、一次情報（C）の出典名とURLが付いているか
- [ ] 品種マスタや商品ページの値をそのまま使っていないか
- [ ] 生産者の経験の文は、大森さんが確認済みか
- [ ] 冬越し・育つ条件を最初に書いているか。弱めていないか
- [ ] 北海道と本州で違うことを分けて書いているか
- [ ] 高さの使い分けは教本 第1章の基準に合っているか
- [ ] 内部の言葉がお客様向けの文に入っていないか
- [ ] 在庫のない品種にリンクを付けていないか
